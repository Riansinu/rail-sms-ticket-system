# 🚆 Rail SMS Ticket

A mobile-first prototype that enables **unreserved train ticket booking without internet**, using simple SMS-based interaction.

Built to improve accessibility for **rural users and low-end phone users**.

---

## 📌 Problem

Booking unreserved train tickets requires internet access, smartphones, or long queues at stations.
This creates barriers for users with:

* Limited connectivity
* Basic mobile devices
* Low digital literacy

---

## 💡 Solution

Rail SMS Ticket allows users to:

* Enter journey details in a simple UI
* Automatically generate an SMS in the correct format
* Send it to **139 (Railway service number)**
* Receive a ticket confirmation code via SMS

---

## ✨ Features

* 📱 **No Internet Required** after SMS generation
* 🎟️ **Quick Ticket Booking** in 3 steps
* 🧾 **Ticket History Tracking**
* ✅ **TTE Verification System**
* ❓ **Built-in Help & SMS Format Guide**
* 🌐 Designed for **low-end devices & accessibility**

---

## 🛠️ Tech Stack

* React (Frontend Prototype) 
* Inline styling (custom UI system)
* Component-based architecture

---

## 🔄 User Flow

1. Enter journey details
2. Generate SMS
3. Send SMS to 139
4. Receive ticket code
5. Show code to TTE for verification
